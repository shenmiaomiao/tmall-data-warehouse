# tmall-data-warehouse 电商四层数仓构建与商品爆款预测项目
## 一、项目背景
电商平台商品海量，人工筛选爆款成本高、效率低。本项目基于天猫电商公开数据集，严格按照 **ODS-DWD-DWS-ADS 四层数仓分层架构** 完成数据仓库建模，对用户行为、商品属性、交易数据进行多维度清洗与聚合分析；通过机器学习模型实现商品爆款预测，挖掘影响爆款的核心特征，为电商选品、流量投放、商品运营提供数据决策支撑。

## 二、技术栈
Python、Pandas、NumPy、Matplotlib、Seaborn、Scikit-learn、PCA、K-Means、LightGBM

## 三、项目能力覆盖
- 数据处理：缺失值填充、异常值过滤、数据去重、特征衍生与标准化
- 可视化分析：分布分析、相关性热力图、指标对比图表，完成全量EDA探索
- 无监督学习：PCA特征降维、K-Means用户聚类，结合轮廓系数评估聚类质量，实现用户画像分群
- 有监督建模：搭建逻辑回归、决策树、LightGBM多组对比模型，基于AUC、F1、精确率、混淆矩阵综合评估模型效果

## 四、仓库文件说明
- tmall-data-warehouse.py：项目全套源代码，包含数仓分层、数据清洗、EDA分析、聚类、特征工程、模型训练与评估完整流程
- requirements.txt：项目所有依赖库清单，可一键部署运行环境
> 说明：原始数据集体积较大未上传，替换本地数据路径即可完整复现项目流程

## 五、数仓四层架构流程
1. **ODS原始层**：接入天猫原始用户行为、商品、交易数据表，保留原始数据口径
2. **DWD明细层**：清洗脏数据、处理缺失与异常值，规整字段，生成高质量明细基础数据
3. **DWS汇总层**：基于商品、用户维度做指标聚合，统计曝光、浏览、加购、转化、价格、评分等核心业务指标
4. **ADS应用层**：整合分析特征，产出最终建模数据集，用于用户分群与爆款预测建模

## 六、模型结果
对比传统机器学习模型，**LightGBM模型拟合效果最优**，AUC、F1分数显著优于逻辑回归、决策树模型。
通过特征重要性分析得出：**商品价格、曝光流量、加购转化率、用户好评率**是决定商品成为爆款的四大核心因素。

## 七、运行方式

pip install -r requirements.txt
python tmall-data-warehouse.py

完整掌握电商行业四层数据仓库建模思维与业务指标体系，熟练独立完成「数据清洗 - 探索性分析 - 特征工程 - 用户分群 - 建模预测 - 模型评估 - 业务解读」全流程数据分析项目，能够将机器学习模型结果转化为可落地的业务运营建议。
